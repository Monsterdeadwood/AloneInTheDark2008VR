# Alone in the Dark 2008 VR — project status

[← Project page](../README.md) · [Flat2VR testing & discussion](https://discord.gg/P4q9zt7ek)

Reviewed **14 November 2026**. Documented branch: **R22 / Meta 2048 preview**.

## What has been checked

- Item grips, held-bottle wall contact and original throw routing were checked in the actual game with XR Sim/Tape.

## Current limits

- Physical Meta acceptance and a 72 FPS target are not established.
- Two-hand grips, empty-hand contact, rotation at walls, pushing and vibration need further validation.

## Build access

Ask for the current complete test package in the game’s Flat2VR thread. A local build record does not by itself mean a file has been uploaded to this repository’s Releases.

## Documentation basis

This overview was reconciled against the project’s recorded package notes and validation records. The following names identify the records reviewed; they are not download links:

Game execution, simulator validation and physical-headset feedback are reported separately above. Features from a separate experimental branch are identified explicitly.

## Кратко по-русски

Экспериментальная VR-ветка PC-версии Alone in the Dark 2008: удерживаемые предметы от контроллеров, инвентарь и штатное поведение броска.

- Принятие в физическом Meta-шлеме и целевые 72 FPS пока не подтверждены.
- Двуручные хваты, контакт пустой руки, вращение у стены, толкание и вибрация требуют дальнейшей проверки.
